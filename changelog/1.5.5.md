# 1.5.5 — 流式朗读漏句

## 症状

流式模式下，多步骤回复只读出其中一部分：有时整句不读，有时整行只读后半截。

## 成因

两个语义不匹配的实现叠加：

- `turnContent()` 在 Turn 生成过程中只返回**最新一个 step** 的文本。模型每开一个
  新步骤，这段文本就被整体替换。
- `streamCursors` 的游标却按**整个 Turn** 累计，只增不减。

于是步骤切换时文本变短、游标却没回退，新步骤开头与旧游标等长的部分被整段跳过。

## 修复

新增 `streamCursorFor`：游标携带上次的文本，只有当当前文本仍以已读内容开头时才
延续游标，文本被替换则归零。

```js
const streamCursorFor = (prev, text) => {
  if (prev === undefined || prev === null) return 0
  const cursor = typeof prev.cursor === 'number' ? prev.cursor : 0
  if (cursor <= 0) return 0
  const seen = typeof prev.text === 'string' ? prev.text : ''
  return text.slice(0, cursor) === seen.slice(0, cursor) ? cursor : 0
}
```

`streamCursors` 的值类型由 `number` 改为 `{ cursor, text }`。
